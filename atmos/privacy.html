Atmos Privacy Notice
Overview

Atmos is Sercle’s browser-based digital-home experience. This notice explains the information handled by the current public Web version of Atmos.

Resident information stored in your browser

The current version stores resident and product state in your browser. This includes information you enter when creating a resident and state created while using Atmos. Durable product state is stored in the browser’s IndexedDB database named atmos-v1; Atmos may also use a browser local-storage entry for a local snapshot or preference state.

This resident information is local to the browser profile and device where it was created. The current version does not provide a production Sercle account backend, cloud synchronization service, or application API that uploads resident state to Sercle.

Browser-local state may remain until you remove it through Atmos where a relevant control is available, clear the site’s data using browser controls, or the browser or device removes it. Clearing browser data, changing browsers or devices, using some private-browsing modes, or restricting storage can cause local state to become unavailable or be permanently lost.

Hosting requests and operational logs

Atmos is delivered using Vercel hosting. When your browser requests Atmos pages and assets, ordinary network information necessarily leaves your device. Vercel and Sercle may process request information such as an IP address, browser or user-agent information, requested URL, request time, response status, and diagnostic, availability, abuse-prevention, or security information to deliver, protect, troubleshoot, and operate the service.

These hosting requests and operational records are distinct from the resident and product state stored in atmos-v1. Sercle does not claim that no data ever leaves your device, because ordinary hosting and network request metadata exists even though resident state remains browser-local in the reviewed version.

Sercle does not state a fixed Vercel retention period or processing location in this notice because those provider facts have not been independently fixed for this Atmos release.

Analytics, telemetry, and external runtime requests

The reviewed Atmos Web artifact does not include a production visitor-analytics integration, product telemetry integration, crash-reporting integration, or active application backend. Qualification of the accepted release observed no resident-data transmission and zero required external runtime requests while the product started, stored state, and reloaded with non-loopback origins unavailable.

This qualification describes the reviewed release and does not eliminate ordinary requests to the Vercel-hosted Atmos origin or Vercel’s operational hosting logs. Preview-only Vercel tooling is not part of the production-target artifact.

Accounts, cloud services, payments, and audio

The current version does not provide production cloud accounts, production authentication services, cloud backup or synchronization, paid subscriptions, purchases, or paid features. A locally created resident is browser-local and is not a production Sercle cloud account.

The current Atmos V1 release does not provide audio playback. Descriptive references to ambience or an audio layer do not mean that audio is recorded, played, uploaded, or analyzed.

Use, retention, and deletion

Browser-local resident state remains subject to the browser and device controls described above. Hosting information may be used to deliver Atmos, maintain availability, diagnose failures, prevent abuse, protect security, and comply with legal obligations. Email and operational records may be retained as reasonably necessary for support, security, legal compliance, and service operation, subject to applicable law and provider controls.

Sercle does not sell resident information submitted to the current Atmos application.

Security and storage limitations

Sercle uses reasonable measures appropriate to the current static Web service, but no browser storage or network service can be guaranteed completely secure or continuously available. You are responsible for controlling access to your browser profile and device. Do not enter information into Atmos that you are not prepared to store locally on that device.

If durable browser storage is unavailable or restricted, Atmos may fail closed rather than claim that state was saved. The current release may not provide a designed explanation for every storage-restricted condition.

Children

Atmos is a general digital-home experience and is not directed specifically to children. The current version does not provide a production cloud registration flow or payment flow. A local resident identifier should not be used to enter unnecessary personal or contact information.

Changes

Sercle may update this notice when Atmos behavior changes. Accounts, cloud synchronization, analytics, telemetry, paid services, audio processing, or new resident-data transmissions require renewed factual and legal review and an updated notice where appropriate.
